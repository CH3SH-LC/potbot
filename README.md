# potbot

**出门前不用再打开五个 App，说一句话，拿到那个文件。**

potbot 是一个面向 Android 的任务式智能体交互层。你给出目标，它自己组织协作、调用工具、把结果做成真实可编辑的文件；只有在需要花你的钱、动你的账号时，它才停下来问你。

---

## 一、问题：软件按功能切分，人的需求按任务出现

要做成一件事，今天你实际经历的是：

> 想清楚 → 拆成步骤 → 判断该用哪个软件 → 打开它 → 找到那个入口 → 操作 → 导出 → 发给别人

工具本来是能力的容器，却成了注意力的税。你要的从来不是"打开 Excel"，而是"把这周的支出理清楚"；不是"打开 Word"，而是"写一篇能发给团队的通讯"。**软件的边界是功能，人的边界是任务**——两者错位的地方，就是每次操作里被消耗掉的那部分注意力。

大模型让"理解任务"第一次变得可行，但把对话放进一个聊天框，只是把问题换了个形态：你仍然要自己拆步骤、自己找工具、自己把结果搬出来、自己拼接成能用的东西。**会聊天的，不等于会干活的。**

---

## 二、主张：以任务为单位，而不是以应用为单位

potbot 的五个基本取舍：

**唯一入口。** 不为每种能力造一个页面。目标用自然语言说一次，剩下的判断交给它。

**临时组织。** 需要多个能力协作时，为这次任务临时组一个"群"，任务结束即解散。组织是临时的，能力是常备的——就像你不会为了搬一次家而成立一家公司。

**交付物，而非回答。** 价值的终点是一个能继续编辑、能被别人打开的文件，不是一段看起来不错的文本。文件要能被改，改完还要能被再次改。

**决策气泡，而非默默代劳。** 涉及真实花费、真实账号、真实外部动作时，把"即将发生什么、对象是什么、金额是多少"摆到台面上，让你确认一次。确认是逐次的、有边界的，不是一劳永逸的授权。

**能力在你自己的设备上。** 业务逻辑、记忆、文件与密钥留在设备本地；联网的只是推理与已获授权的第三方服务。你的资料不该因为"用了 AI"就默认离开你的手。

---

## 三、设计立场

这些立场贯穿整个项目，也是判断"某个改动该不该做"的依据。

**任务优先于功能。** 新增能力时先问"它服务于哪类任务"，而不是"它能做什么"。功能清单会不断膨胀，任务清单不会。

**交付物优先于回答。** 一个能继续编辑的文件，比一段流畅的解释更接近"完成"。所有围绕文档的设计，最终都在服务这一条。

**可复现优先于看起来对。** 同一份输入应当产生同一份输出。这听起来是技术细节，其实是信任的前提——你今天能接受的结果，明天不该变成另一个样子；你要发出去的文件，不该每次都不一样。

**证据优先于宣称。** "做完了"不等于"真的变了"。系统的诚实程度，取决于它是否愿意在没做到的时候说自己没做到——包括承认失败、承认未知、承认"这次改动其实没有产生任何变化"。

**确认优先于自动完成。** 自动化容易让人放松警惕，而钱的错误不可逆。宁可多停一次，也不要替用户做一次他并没有真正同意的决定。

---

## 四、展望

potbot 想走的方向，不是"更能聊"，而是"更接近一个可信的做事者"。

**从生成到维护。** 现在它能产出文件；往前一步，是长期维护一份文件——记住上次为什么这么改、这次改动与哪条事实冲突、哪些结论已经被推翻。文件是有历史的，工具应当理解这件事。

**跨文档的一致性。** 同一件事往往同时活在文档、表格和演示里：表格里改了一个金额，通讯稿里的说法就该跟着变。让一份事实在所有产出物里保持同一版本，是一个尚未解完、但方向明确的题目。

**模板作为能力单元。** 与其让用户描述每一种需求，不如把高频任务沉淀成可声明、可安装、可授权的能力单元——文档、表格、演示、外卖、时钟、日历、检索都可以是这样一件"可被叫来的工具"。生态的意义在这里，而不在插件数量。

**设备侧的边界继续外扩。** 推理与外部服务必然联网，但其余部分——记忆、文件、密钥、业务逻辑——应当尽可能留在设备上。这不是技术炫技，而是对"谁的资料"这个问题的回答。

**诚实的自动化。** 越强的自动化，越需要把"它做了什么、没做什么、不确定什么"说清楚。这一条不是功能，是底线；它决定了这项技术是帮人做决定，还是替人做决定。

---

## 五、当前状态

这是一个进行中的项目，不是一个已完成的产品。仓库里包含内核源码、契约、测试与 Android 宿主；构建与使用方式见 [USAGE.md](USAGE.md)。

有几点如实说明：

- 应用界面已在真机运行，任务执行需要本机宿主配合（见 USAGE）；
- 涉及外部平台的动作，受该平台实际授权范围限制，未获授权的能力不会被伪装成可用；
- 系统中所有"未验证"的能力都按未验证标注，不以演示结果代替真实结论。

—— **少找按钮，少切应用。**
